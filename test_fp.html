📐 阶段 1：构建全局骨架（window / document / navigator）

这是所有补环境的基础，必须最先处理。核心原则：

  • window = global（Node.js 全局对象即 window）
  • window.__proto__ = Window.prototype（确保 window instanceof Window 为 true）
  • 清理 Node.js 特有全局变量（GLOBAL、root、__filename）
  • 注入 Node.js 原生对象（Math、Date、JSON、Promise…）
// === 阶段 1 骨架代码 ===
Window = function Window() {};
setNativeTag(Window.prototype, 'Window');       // Symbol.toStringTag = "Window"
window = global;
window.__proto__ = Window.prototype;            // instanceof Window ✅
self = top = parent = window;

// 清理 Node 痕迹
try { delete GLOBAL; } catch(e) {}
try { delete __filename; } catch(e) {}

// 注入必需全局
window.Math = Math;
window.Date = Date;
window.JSON = JSON;
window.parseInt = parseInt;
// ... 其他原生对象

📐 阶段 2：构建构造函数 + 原型链（核心）

这是补环境最关键的步骤。真实浏览器中 每个 DOM 对象都有构造函数和原型链，很多脚本会检测 instanceof 和 Object.prototype.toString.call()。

步骤代码验证
1. 定义构造函数Navigator = function Navigator() {}Navigator.name === "Navigator"
2. 定义原型方法/属性Navigator.prototype = { get userAgent() {...}, ... }属性可读写
3. 设置 Symbol.toStringTagsetNativeTag(Navigator.prototype, 'Navigator')Object.prototype.toString.call(navigator) === "[object Navigator]"
4. 创建实例navigator = {}; navigator.__proto__ = Navigator.prototypenavigator instanceof Navigator === true
5. 挂载到 windowwindow.navigator = navigator全局可访问

📐 阶段 3：逐维度补实现（合成模式 vs 真实数据注入模式）

每个指纹维度支持两种模式：

  • 合成模式（默认）：用 seed 生成固定但独特的指纹值，适合测试、批量生成不同设备指纹
  • 真实数据注入模式：从真实浏览器采集指纹后 原样回放，Node.js 输出与浏览器完全一致

📐 阶段 4：toString 伪装（safeFunction）

很多风控脚本会检测函数 toString() 是否返回 "function xxx() { [native code] }"。如果返回的是真实函数体，说明环境被篡改过。

// === toString 伪装机制（参考 run_js_proto.js / _ab_env_ok.js）===
const _native_toString_symbol = Symbol('function_toString');

// 1. 劫持 Function.prototype.toString
!(function patchToString() {
  const originToString = Function.prototype.toString;
  Object.defineProperty(Function.prototype, 'toString', {
    value: function toString() {
      // 如果函数上有 _native_toString_symbol 标记，返回伪造字符串
      return this[_native_toString_symbol] || originToString.call(this);
    }
  });
})();

// 2. 给任意函数打上 native 标记
function updateFunToString(func) {
  Object.defineProperty(func, _native_toString_symbol, {
    value: `function ${func.name || ''}() { [native code] }`
  });
}

// 3. 使用
updateFunToString(Navigator);
updateFunToString(HTMLCanvasElement);
updateFunToString(Document);
// Navigator.toString() → "function Navigator() { [native code] }" ✅
