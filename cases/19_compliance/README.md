# 案例 19：爬虫合规 — 司法判例与合法边界

> 📖 合规型案例（基于公开判例整理）。技术之外，爬虫的第一道边界是**法律**。
> 开源仓库尤其需要这一节：同样的代码，用途不同，性质完全不同。

## 核心判例

### 大众点评诉百度不正当竞争案

- 百度爬取大众点评用户点评数据用于自己的地图服务，被判**不正当竞争**，
  赔偿 **300 万元**
- 该案入选 2017 年上海法院知识产权司法保护十大案件、
  《中国审判》2016 十大典型案例
- 裁判要旨：爬虫技术本身中立，但**大规模抓取他人平台的核心数据用于竞争性产品**，
  违反诚实信用原则与公认商业道德

### 北京互联网法院（2026 年）平台数据案

- 不正当获取、使用平台用户数据，认定构成不正当竞争，判令赔偿经济损失

## 合法边界的判断维度（公开资料共识）

| 维度 | 合法倾向 | 违法倾向 |
|------|---------|---------|
| 数据性质 | 公开数据、个人公开信息 | 非公开数据、个人敏感信息 |
| 抓取规模 | 低频、少量 | 高频、全量、绕过防护 |
| 使用目的 | 研究、个人学习、正当业务 | 直接竞争、倒卖数据、牟利 |
| robots 协议 | 遵守 | 无视并绕过 |
| 技术手段 | 普通访问 | 破解验证码/签名/风控 |
| 影响 | 无实质影响 | 干扰正常运营、危及数据安全 |

## 对本仓库的提醒

- 本仓库所有「逆向/对抗」案例都是**学习与研究**性质，请勿用于
  违反目标网站服务条款或法律法规的抓取
- 「绕得过去」≠「合法」：司法实践关注的是**抓什么、抓多少、用来干什么**
- 企业场景务必先做合规评估（数据来源、授权、个人信息保护）
